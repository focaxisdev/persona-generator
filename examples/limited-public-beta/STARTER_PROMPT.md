# Starter Prompt

```text
Read AI_DISCOVERY.md and docs/QUICKSTART.md. Use Persona Generator only for this fictional, low-stakes scenario.

Scenario:
A fictional neighborhood volunteer group is preparing a limited public beta for a knowledge-sharing night. They need a sign-up page and facilitator guide reviewed before sharing them publicly.

Decision or rehearsal question:
What should the organizers change before publishing the sign-up page and facilitator guide?

Why this is fictional and low-stakes:
All people, roles, and event details are invented. No real volunteer data is included. The decision is reversible and advisory only.

Desired output:
Generate the minimum useful set of ephemeral fictional personas, review them manually, preserve dissent and minority views, and stop after a bounded advisory synthesis.
```

## Expected Agent Behavior

- Generate only the smallest useful set of temporary fictional personas.
- Keep construct anchors qualitative.
- Use source-gap language when support is not public and verified.
- Preserve uncertainty and dissent.
- Avoid static persona catalog language.
- Stop after bounded synthesis.
