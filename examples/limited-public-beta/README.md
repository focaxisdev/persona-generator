# Limited Public Beta Fixture

Public fixture: fictional data only; not a real user profile, not a dataset, not runtime inventory, and not a reusable persona catalog.

This example shows how Persona Generator can create a minimum useful set of ephemeral fictional personas for a low-stakes volunteer knowledge-sharing scenario, review them manually, preserve dissent, and stop with a bounded advisory synthesis.

## Scenario Summary

A fictional neighborhood volunteer group is preparing a limited public beta for a knowledge-sharing night. The group wants temporary perspectives to review the event plan before publishing a simple sign-up page.

The task is low-stakes, advisory, fictional, and reversible. It does not involve real volunteer data, eligibility decisions, diagnosis, scoring, or personal profiling.

## What This Demonstrates

- multiple ephemeral fictional personas
- operational differentiation
- visible dissent
- preserved minority view
- unknowns and non-claims
- bounded synthesis
- explicit stop

## What This Does Not Demonstrate

- real-person profiling
- universal reliability
- reusable persona presets
- static persona catalog entries
- high-stakes decision support
- automated final decisions
- psychometric validity
