# Code of Conduct

## Expected Behavior

Participants are expected to:

- collaborate respectfully
- stay within the project's fictional, low-stakes, advisory scope
- avoid harassment, identity attacks, coercion, or intimidation
- respect privacy and consent boundaries
- avoid posting real personal data, secrets, or sensitive material
- accept maintainer decisions on safety boundaries

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment or discriminatory language
- threats or intimidation
- doxxing or posting private information
- using the project to profile, score, diagnose, manipulate, or target real people
- repeatedly pushing prohibited use cases after maintainer correction
- fabricating citations or misrepresenting evidence

## Enforcement

Maintainers may remove content, close issues, reject pull requests, limit participation, or block participants when behavior violates this code.

Before public release, maintainers must add an owner-approved enforcement contact.
