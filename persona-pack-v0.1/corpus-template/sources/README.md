# Corpus Sources

Place source files for this Persona Pack in this folder.

## Source File Rules

- Use Markdown or plain text.
- Give each source a Source ID in `corpus-manifest.md`.
- Keep location references stable enough for manual review, such as section names, paragraph labels, or line ranges.
- Mark fictional sources clearly as fictional.
- Do not include non-consented third-party private material.
- Do not include secrets, credentials, or unnecessary personal data.

## Suggested Source Header

```md
# SRC-001 - Source Title

- Source ID: SRC-001
- Source status: fictional / self-provided / consent-based
- Source type:
- Location reference style:

## Text


```
