# Evidence Ledger

## Evidence Rules

- Separate observation from interpretation.
- Link every record to a Source ID and source location.
- Use only `high`, `medium`, `low`, or `unknown` confidence.
- Record counterevidence status.
- Do not use theory mapping alone as evidence for operational claims.
