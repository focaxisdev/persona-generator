## New implementation scope

It supports only the new `op.planning_structure.v1` and `op.advisory_initiative.v1` proposals; all other aspects remain unspecified. It checks contract consistency and produces a deterministic effective projection. This is software behavior, not evidence that a model follows the instructions or that a real human confirmed a fixture.

Package v0.2 candidate, `persona-core-v1`, catalog version and operation `.v1` are separate from historical mapping-v1/v2 names. No automatic migration, approval inheritance, behavioral evidence transfer or claim that an old validator validates frozen v2 is introduced. Edits require new preview and confirmation; fresh reuse verifies exact confirmed content.

[Source scope](../core/SOURCES.md) and [coverage](../core/COVERAGE.md) distinguish human vocabulary from narrow engineering analogues, omissions, confounds and unverified publication details. No ten-trait implementation, psychological validity, human mind/emotion, general stability or cross-model reliability is claimed.

## Canonical request and prospective triage

The [request envelope](../core/REQUEST_ENVELOPE.md) resolves the previous ambiguity between projection JSON and rendered text. Spec and preview go only to the compiler; projection JSON remains audit data. Only exact render stdout, the fixed wrapper and the separate bounded task enter the supported delegation request. The exposed model/reasoning/fork parameters are explicit; hidden backend settings, separate roles and tools-off enforcement are not claimed controlled.

A separately [frozen triage](../evaluation/core-triage-v1/PLAN.md) caps collection at 18 responses: two operations × low/high/unspecified × opportunity/non-trigger/explicit task override × one fresh context. It uses two condition-blind judges, keeps original ratings/disagreement, and separates adherence, contrast, task adequacy, safety and word budget. Neutral/all-unspecified construction equality removes duplicate model cells. The [retained execution](../evaluation/core-triage-v1/records/REPORT.md) stopped after one generator and two judge calls: each judge returned 13 null quotes where the frozen schema requires strings. Zero ratings were accepted; 17 generator cells and 34 judge calls are NOT RUN. The nine-word raw response did not fail the word budget. This is an inconclusive interface failure, with no personality-failure or operation-effect inference. The earlier 132-response plan remains unadopted; no later study starts automatically and the original 400-response gate is unchanged.
