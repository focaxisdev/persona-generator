# Release acceptance — unreleased desired-trait profile candidate

## Desired-trait product acceptance remains separate

The active candidate targets [installable, composable agent/subagent profiles](../PROJECT_PURPOSE.md): ten independently selectable BFAS aspect settings and thirty original anchor hypotheses. Independent selection implies neither statistical independence, zero correlation nor a validated joint distribution. The unchanged legacy core implements two diagnostic operations; that limit does not describe the profile layer. [Profile verification](../profiles/VERIFICATION.md) separates local persistence, bindings and disposable loading checks from actual host use. Persisted files and deterministic rendering do not prove stable model behavior; the new hypotheses have no behavioral validation.

Before any release decision, review ten-aspect semantic coverage and proxy limitations; verify real private owner choice/short-answer confirmation and revisions; verify the declared host application path without assuming automatic loading; and prospectively assess composition, task overrides, repeated/fresh contexts, stable identity and parent/subagent application. Repository-guided explicit loading is a supported product path; native discovery is a separate optional claim and does not require a nested CLI. Static passing fixtures do not satisfy behavioral or authentic-owner requirements. A bounded revised behavioral acceptance proposal must state its claim scope and be separately reviewed; it cannot silently replace the original 400-response gate.

The six-cell diagnostic remains paused. No remaining cell, new study, merge or release is authorized by this checklist. GitHub documentation is the marketing surface; standalone website work was a coordinator scope error and is not a release requirement.

**Current status:** [Rating-contract v2 is paused for scope alignment](../evaluation/core-triage-v2/records/REPORT.md) after six retained answers (one exact carried answer and five new), 12 fresh locked schema-valid ratings, and 17 new diagnostic calls. Its frozen preparation **NOT RUN** statements are historical; continuation is not automatically authorized. The two operations are limited diagnostics. The intended final product remains an installable, composable, psychology-grounded specification for agents and subagents; behavioral persistence and composition effects remain unverified. Historical v1 outcomes and other unrun studies retain their original status.

This is a prospective review plan, not a release, tag, merge authorization, or replacement for frozen historical gates. The canonical reader route is [README](../README.md) → [Quickstart](QUICKSTART.md) → [profile contract](../profiles/CONTRACT.md), with the [legacy core contract](../core/README.md) retained for its diagnostic path. GitHub documentation is the marketing scope.
