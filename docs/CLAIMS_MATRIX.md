# Claims Matrix — v0.2 candidate

Use this matrix for documentation, future release notes, and the future marketing page. `Verified source` refers only to the identified human research vocabulary; it never transfers to agent behavior.

| Claim | Evidence and current status | Allowed wording | Not supported |
| --- | --- | --- | --- |
| Named psychological foundation | [Source ledger](../persona-design-v0.2/sources.md) and [registry](../persona-design-v0.2/construct-registry.md) | “Uses traceable definitions of ten Big Five aspects from DeYoung, Quilty, and Peterson (2007).” | “Scientifically validated AI personality.” |
| Behavior translation | Original mapping hypotheses, per-aspect source and mapping IDs | “Proposes observable agent behavior rules for user review.” | “BFAS research proves these agent rules.” |
| Interview | Original design-intent choices and short answers | “Configures desired agent behavior.” | Personality assessment, percentile, diagnosis, inference about the user's real traits. |
| Qualitative goals | Low/middle/high/unspecified in approved spec | “User-selected design targets.” | Human norms, psychometric scores, or treating unspecified as middle. |
| Static checks | Reproducible local validator and negative fixtures | “Checks the declared artifact contract.” | Proof of actual consent, factual correctness, semantic safety, or behavior quality. |
| Agent behavior | No completed model pilot for this increment | “Behavioral evaluation pending; mappings remain proposed.” | Reliable adherence, validated personality, or demonstrated cross-model stability. |
| Markdown handoff | Contract and reload test procedure; v0.2 empirical trial pending | “Portable text format with explicit reload checks.” | Universal model portability or stability. |
| Human mind and emotion | No evidence or intended claim | “Fictional behavioral instructions.” | The agent possesses feelings, a human mind, clinical traits, or human personality. |
| Invariants | Required constraints plus static/manual checks and pending behavior tests | “Personality settings cannot authorize changes to accuracy, privacy, safety, or tool permissions.” | Guaranteed safety or authority to override a host's permissions. |

A later successful pilot may support only its recorded model, settings, scenarios, outputs, and rubrics. Retain failures and inconclusive/not-elicited results. Do not promote a narrow observed contrast into construct validity or broad readiness. Future marketing must link to this matrix and the actual evidence ledger next to any behavioral claim.
