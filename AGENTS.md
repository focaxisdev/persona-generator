# Instructions for AI Agents

Persona Generator is a public distribution workspace for protocol-first fictional persona generation.

## Read First

1. [AI_DISCOVERY.md](AI_DISCOVERY.md)
2. [docs/QUICKSTART.md](docs/QUICKSTART.md)
3. [docs/SAFETY_BOUNDARIES.md](docs/SAFETY_BOUNDARIES.md)

Read only the smallest task-specific path. Do not crawl the full repository by default.

## Core Rule

`Persona Generator stores the grammar for generating personas, not a catalog of predefined personas.`

## Allowed Default Use

- Fictional scenarios only.
- Low-stakes advisory work only.
- Ephemeral personas by default.
- Manual review before downstream use.
- Human final judgment always required.

## Prohibited Use

- Real-person covert profiling.
- Diagnosis or clinical claims.
- Psychometric scoring.
- Sensitive-attribute inference.
- Hiring, surveillance, legal, medical, credit, insurance, or educational placement decisions.
- Static persona catalog expansion.
- Autonomous final decisions.

## Stop Rule

Stop when the bounded task is complete. Do not add personas, panels, persistence, or claims merely for completeness.
